# CLAUDE.md

Keep code **elegant and very simple**. This is a hackathon — simplicity dominates over security and complexity.

## Project
An app built on the **AG-UI** and **A2A** protocols for real-time agent-UI streaming.

## Rules
- Minimal abstractions — if it can be one file, keep it one file
- No over-engineering: no factories, no dependency injection, no "future-proof" design
- Prefer readable over clever
- Skip error handling for edge cases that won't happen in a demo
